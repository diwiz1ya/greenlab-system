# GreenLab Operations Manual (EN, No Rework)

Published HTML manual for operators, QA, and support.

- Main file: `index.html`
- Screenshots: `assets/screens/*.png`

## Publish via GitHub Pages

1. Push repository changes to GitHub.
2. In repository settings, open **Pages**.
3. Set source to **Deploy from a branch**.
4. Choose branch (usually `master`) and folder **`/docs`**.
5. Save and wait for deployment.

After deployment, open:

- `https://<org-or-user>.github.io/<repo>/manual-en/`
